# 《雾都1937》网站 · 使用说明

## 项目简介
这是一个以抗战时期重庆为背景的交互式历史体验网站，通过身份扮演、地图探索、分支选择等游戏化方式，让用户沉浸式感受战时重庆普通市民的命运。

## 如何运行
1. 双击打开 `index.html` 文件
2. 选择你的身份，开始探索
3. 所有数据保存在浏览器本地，关闭后再打开进度还在

## 如何打包移植到其他电脑
整个文件夹（`雾都1937`）拷贝到任意电脑即可使用：
- 支持 Windows / Mac
- 无需安装任何软件
- 无需联网（纯静态网页）
- 用 Chrome / Edge / Safari 浏览器打开效果最佳

## 项目结构
```
雾都1937/
├── index.html              ← 首页（入口）
├── 雾都1937·网站策划文案.md   ← 策划案文档
├── README.md               ← 本文件
├── assets/
│   ├── css/style.css       ← 全局样式
│   ├── js/main.js          ← 核心交互逻辑
│   ├── images/             ← 图片资源（预留）
│   └── audio/              ← 音频资源（预留）
└── pages/
    ├── map.html            ← 重庆城区地图（核心枢纽）
    ├── archive.html        ← 档案柜（收集物）
    ├── characters.html     ← 人物谱
    ├── timeline.html       ← 时间轴
    └── scenes/
        ├── dock.html       ← 朝天门码头
        ├── tunnel.html     ← 较场口大隧道
        ├── newspaper.html  ← 新华日报社
        ├── airport.html     ← 广阳坝机场
        ├── school.html     ← 沙坪坝学校
        └── ciqikou.html    ← 磁器口古镇
```

## 操作提示
- 灰色地点 = 尚未解锁，完成当前场景后会自动解锁新地点
- 探索过程中可以拾取历史物件，收入"档案柜"
- 点击顶部导航栏可在各页面间跳转
- 进度自动保存在浏览器中
